# Zanokusha Enterprise

A website for Zanokusha Enterprise, a family-owned agricultural business based in Ndlangubo, KwaZulu-Natal, South Africa.

## About

Zanokusha Enterprise is committed to providing high-quality, locally sourced agricultural products to communities and supermarkets across the region. We specialize in fresh, locally grown produce including spinach, cabbage, and maize.

## Project Structure

```
Files/
├── Index.html          # Home page
├── about.html          # About Us page
├── product.html        # Products page
├── contact.html        # Contact Us page
├── enquiry.html        # Enquiry form page
├── style.css           # Stylesheet for all pages
└── Images/             # Image assets directory
    ├── Zanokusha enterprise logo.png
    ├── Hero.jpg
    ├── Cabbage.jpg
    ├── Maize.jpg
    ├── Red cabbage.jpg
    └── back.jpg
```

## Pages

- **Home (Index.html)** - Welcome page with company introduction and quick links
- **About (about.html)** - Company story and background information
- **Products (product.html)** - Showcase of agricultural products offered
- **Contact (contact.html)** - Contact information and communication channels
- **Enquiry (enquiry.html)** - Customer enquiry form for product orders and queries

## Features

- Responsive navigation menu
- Professional branding with company logo
- Product showcase
- Local image assets loaded from the `Images/` folder
- Contact and enquiry forms
- Consistent styling across all pages
- Green and gold color scheme reflecting agricultural heritage

## Image Assets

All image paths are relative to the HTML pages and use the format `Images/filename`.

- **Zanokusha enterprise logo.png** - Website logo used in the navigation header
- **Hero.jpg** - Home page hero image and agricultural produce image
- **Cabbage.jpg** - Cabbage images on the About and Products pages
- **Red cabbage.jpg** - Red cabbage image on the Products page
- **Maize.jpg** - Maize image on the Products page
- **back.jpg** - Farm location image on the Contact page

Keep image filenames and letter casing unchanged when adding or replacing assets.

## Color Scheme

- **Page Green**: #9BF7A0 (Background)
- **Header Green**: #2E7D32 (Navigation header)
- **Gold Accent**: #E4A405 (Text and links)
- **Brown**: #621B02 (Headings)

## Getting Started

1. Open `Index.html` in a web browser to view the website.
2. Keep the `Images/` folder in the same directory as the HTML files so all images load correctly.
3. Navigate through the menu to explore different sections.
4. Use the Contact or Enquiry pages to get in touch.

## File Descriptions

- **style.css** - Contains all styling for layout, typography, colors, and responsive design
- **Images/** - Stores product images, logo, and background images used throughout the website
